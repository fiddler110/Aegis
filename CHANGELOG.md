# Changelog

Aegis's changelog lives at [research/releases.md](research/releases.md) — every shipped feature,
why it was built, what it touched, and how it was tested. For what's currently open or planned
next, see [research/roadmap.md](research/roadmap.md).

Tagged releases (`vX.Y.Z`) are built and published automatically by
[`.github/workflows/release.yml`](.github/workflows/release.yml); each GitHub Release links back
to `research/releases.md` for the full narrative behind the changes it contains.
